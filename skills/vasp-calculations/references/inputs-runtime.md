# 输入与运行适配

POTCAR 必须与 POSCAR 的物种排列一致；同元素的不同赝势选择也应记录。共享技能只保存选择规则与读取逻辑，不分发赝势内容。

k 点生成需写明 convention：输入间距是倒空间长度还是包含 2π 的量。根据实际倒格矢计算网格，注意 slab 非周期方向与所需 Gamma-only 特例；不要从字符 331 的形式推断所有算法的等价性。

软件变体、补丁和实际二进制决定哪些 INCAR 标记可用。GPU/MPI 布局应使用与当前构建匹配的已验证配方，并在日志中确认实际运行设置；不要把一张 GPU 对应一个 MPI rank 的特定配方推广到所有 VASP 版本与后端。

修改科学协议时保留原输入输出并建立新结果目录。WAVECAR/CHGCAR 可以有各自不同的兼容条件；只有坐标兼容不代表电子状态兼容。

只做静态检查时不运行计算程序。运行测试需要适当资源和已有授权。空 CONTCAR、未收敛电子循环、异常终止或数值发散必须显式报告，不由包装脚本的成功退出覆盖。
