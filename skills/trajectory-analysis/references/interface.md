# 界面分布

## 坐标与区域

明确表面法向、正方向和参考面。可使用逐帧表面位置或固定参考面，但必须记录定义；不同体系晶胞原点变化时不能直接套用相同绝对 z 窗口。上下界面、真空与液体区分开处理。

## 密度

按实际 bin 体积和选定质量/数目归一化。变胞时明确使用逐帧归一化后平均，还是总计数除以累计体积；它们有不同权重。聚合物或固体占据的体积与可接近体积定义要说明。

体相密度按指定窗口统计，界面峰单独报告。区域水数、质量密度与概率密度不是同一个量。积分检查应与所用归一化下的预期粒子数或概率对应。

## 水取向

明确向量，如 O 指向 H-H 中点，以及与正表面法向的夹角。PBC 下先重建 O-H 向量；发生质子转移时说明如何识别水。

平均角度、平均余弦和反余弦后的平均余弦不同。带符号方向和绝对取向不可互换。按角度统计 P(theta) 与按 cos(theta) 统计具有不同测度，不能直接比较形状。

密度乘平均取向是取向加权密度，除非显式引入相应电荷和偶极定义，不称为电荷偶极密度。

## RDF 与配位

明确参考组、目标组、排除自身/同分子项和归一化体积。界面受限区域不一定满足均匀三维 RDF 的标准归一化假设；说明使用的几何或局部定义。
