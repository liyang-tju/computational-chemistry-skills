# 氢键与配位

记录供体、氢和受体的识别方式，分别定义共价键阈值、供受体距离、H 到受体距离和角度。不同文献把角度写为接近 180 度或偏离直线的小角度，必须说明 convention。

几何 cutoff 由任务或明确方法提供，不能沿用另一个体系的私有数值。乙醇等分子不能把所有含氢键都自动当作与水等价的供体。

固定拓扑和反应性轨迹采用不同分子识别。质子交换后，动态归属、短时阈值跨越和真正转移事件需区分；分析过程中不要静默维持错误的旧 O-H 配对。

分别统计溶质作为供体/受体、不同位点、不同水层或不同分子。总数量变化可能来自组成比例变化，不必然意味着每条氢键变弱。

说明计数去重、多重配位和归一化：每溶质、每水、每区域粒子或每帧总数。层间氢键要记录分母和每帧区域成员规则。

比较温度、溶剂或电势时使用一致定义与可比时间窗口。平均距离变化不能直接转换为相互作用能或反应能垒变化。
