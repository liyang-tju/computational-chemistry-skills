# 科学完成判断

按计算类型分别核对“可验收标准”，不以作业退出码为 `0` 或日志非空替代科学审查：

## 1. 各类型验收清单

| 任务类型 | 必须确认的科学验收项 | 常见误判陷阱 |
|---|---|---|
| **单点（SP）** | 电子 SCF 在 `NELM`/`MAX_SCF` 内收敛；正常终止；所需能量/力/电荷密度文件完整写出且无 NaN | 仅提取日志最后一个能量，忽略中间标注 `SCF run NOT converged` |
| **几何优化** | 出现收敛标志（VASP `reached required accuracy`；CP2K `GEOMETRY OPTIMIZATION COMPLETED`）；自由原子最大受力小于目标阈值；结构无断键飞散 | 把达到 `NSW`/`MAX_ITER` 上限退出当成优化完成；把固定层受力混入自由原子判断 |
| **分子动力学（MD）** | 达到目标步数与物理时长；轨迹、`cell`、能量三者长度与步号对齐；温度/势能序列无数值爆炸 | 把输出帧数当 MD 步数；忽略轨迹末尾半帧损坏 |
| **增强采样** | MD 正常推进至目标时长；偏置状态文件同步更新；CV 覆盖预期反应通道并观察到多次往返或采样充分 | 进程跑完就认为自由能收敛；CV 卡死或走偏到非目标副反应未排查 |
| **MLP 训练** | 训练按预设 epoch/早停结束；保留最佳验证点并实际加载导出的推理模型跑通前向预测（能量/力形状与单位无误） | 只看目录里生成了 `compiled.model` 或 `final.pt` 文件名而不验证加载推理 |

## 2. 异常时间序列联合诊断

- **偶发 vs 持续 SCF 不收敛**：单步结构微调期间偶尔出现一次未满收敛警告，若后续步迅速恢复且能量连续，通常可继续观察；若连续多步电子步触及迭代上限，并伴随总能震荡或温度飙升，则自该步起的轨迹段判定为**数值不可靠**，续算应回退至之前正常步。
- **化学完整性扫描**：使用 Python 对整条轨迹（而非只看末帧）计算关键键长或配位变化，记录发生质子转移、分子解吸或副反应的起始步号与持续时间；不要为了凑“预期物种”而静默删帧或替换原子索引。

## 3. 硬件变动与确定性说明

审计不同段的性能或数值差异时，需分开记录：
- **仅计算资源改变**（节点数、GPU 数、MPI/OMP 布局）：由于浮点求和顺序差异，MD 轨迹在数十至数百步后出现混沌发散属正常物理行为，但热力学统计均值应保持一致。
- **科学参数改变**（泛函、截断能、步长、温控）：必须记为不同协议段，不可无标记并入同一统计样本。
