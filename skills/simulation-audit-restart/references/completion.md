# 科学完成判断

按任务分别核对：

- 优化：最终自由原子受力或用户指定判据、实际停止原因、合理末结构。预优化达到步数上限可以进入已计划的下一阶段，但最终阶段不能因此称为收敛。
- MD：目标步数/物理时长、完整轨迹和能量序列、正常结束日志、有效末状态。有限时间内稳定不等于统计收敛。
- 单点：电子收敛、正常结束和预期能量/力/性质输出，不能只检索最后一个数值。
- MLP 训练：训练终止原因、选定模型及导出文件、实际加载和推理结果；文件名中出现 final 或 compiled 不能代替检查。
- 采样：有效窗口、偏置状态、CV 覆盖、过渡和统计效率，程序正常结束与采样充分是不同结论。

异常应结合时间序列判断。孤立 SCF 警告后可能恢复；持续迭代饱和同时伴随温度、能量或几何发散则说明该段不可靠。

化学稳定性扫描全段而不只看末帧。记录断键、成键、质子转移和分子解吸的时间及判据；区分短时涨落与持续事件。不得为保持预期物种而静默更换原子索引或删除反应帧。

恢复时只改变明确必要且已授权的设置。节点或资源变化与科学参数变化分别记录；不保证不同并行布局产生逐位相同轨迹。
