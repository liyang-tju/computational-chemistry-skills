# 建模与验证

先画数据关系并建立简单基线，再决定是否引入复杂组合。样本量、变量数、共线性及测量误差影响系数可辨识性；高训练 R2 不保证解释可靠。

每个样本保留体系、构型族、轨迹、温度或电势等分组。LeaveOneOut 只是逐样本留出；需要未见物种或轨迹评估时采用对应的 group holdout。

特征变换、归一化和筛选只在训练折拟合。数据驱动搜索描述符或调参后评估，需要独立测试或适用的嵌套验证；不能在全部数据筛完公式后把普通 CV 当作无偏性能。

不同粒度分别建模：物种均值相关、轨迹间相关及同物种内部变化有不同解释。可进行组内中心化诊断，但其预测范围与原始总体模型区分。

拟合使用 signed 或 absolute 变量由目标物理量决定。单位变换会改变系数；符号约定和参考 clean/baseline 类别必须随模型保存。异构体和构型类别不能为改善拟合而静默合并。

输出训练指标、交叉验证预测、分组残差及模型公式。经验相关与因果机制分开表述，外推超出训练覆盖时明确适用边界。
