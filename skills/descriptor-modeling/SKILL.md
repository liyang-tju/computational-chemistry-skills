# 描述符与统计建模

基于清晰的物理定义与稳定样本主键构建可解释经验模型（线性回归、Ridge/Lasso、SISSO 或符号回归），严格按目标外推维度做分组交叉验证或嵌套验证，区分拟合表现、样本内插与未见体系外推。

## 开始前确认

- **目标量与粒度**：预测目标 $y$、物理单位与样本粒度（单帧瞬时值、单条轨迹均值，还是物种/表面条件均值）；确认建模与解释处于同一层级。
- **泛化目标**：要检验随机帧内插、跨温度/电势条件泛化，还是**未见催化剂/未见分子物种外推**（决定分组键 `group_id`）。
- **候选描述符与物理假设**：每个候选特征的公式、方向、单位、基准态（如裸表面 clean slab 参考值）与缺失处理。

## 工作流程

### 1. 主键对齐与表完整性校验

- 使用显式稳定主键（如 `sample_id` 或 `(system_id, potential_V)`）合并目标量与特征表，先用外连接排查：
  - 主键拼写差异、异构体名称不一致或缺失行；
  - 意外一对多膨胀（merge 后行数大于预期）。
- **严禁根据能量相近猜配对**，也不把名称不同的异构体/构象静默合并成同一行。

### 2. 定义物理量、符号与基准

为每个特征建立显式元数据表：
- **有符号 vs 绝对值**：同时考虑或明确选用带正负号量（如电荷转移 $\Delta q$、偶极方向 $\cos\theta$）还是模长/绝对值（如 $|\Delta z|$），不可混淆解释。
- **单位与归一化**：明确面积归一化（如每 nm²）还是单吸附质/单水分子归一化，确保符号表达式中的拟合系数带有自洽物理量纲。

### 3. 共线性诊断与简单基线先行

在尝试复杂符号回归或 SISSO 前，先做探索性检查：
1. 检查样本数 $N$ 与特征数 $p$ 比例及特征间相关矩阵 / 方差膨胀因子（VIF），识别高度共线特征组；
2. 拟合单变量 / 低维线性或 Ridge 基线模型，可视化残差，确认复杂公式确实带来统计显著提升而非过拟合噪音。

### 4. 防泄漏验证与嵌套评估（核心）

特征标准化（`StandardScaler`）、特征筛选、正则化超参数调优及 SISSO 符号筛选**必须在训练折内部拟合**（详见 [建模与验证](references/modeling.md)）：
- 评估对新物种/新轨迹的外推能力时，采用 `GroupKFold` / `LeaveOneGroupOut`，不要用样本级 `LeaveOneOut` 伪装跨体系外推；
- 当数据量有限却要搜索大量候选公式时，使用**外层留出测试集或嵌套交叉验证（Nested CV）**，避免在全数据上挑完最佳公式后再报告“普通 CV 分数”。

### 5. 输出模型、分组残差与适用边界

- 对最终模型（包括 SISSO 表达式）给出完整公式、原始变量映射、各系数单位、训练及交叉验证指标（$R^2$、MAE、RMSE）。
- 按组输出残差与离群点列表，明确标出模型有效外推区间，并清楚区分**经验统计相关性**与**已证实的物理因果机制**。

## 按需参考

- `Pipeline` + `GroupKFold` 防泄漏代码、粒度混淆警告（组内 vs 组间相关）与 SISSO 报告规范：阅读 [建模与验证](references/modeling.md)。

## 交付产物与验收

1. **`descriptors.csv`** 与 **`sample_mapping.csv`**：完整特征矩阵、主键、分组列与缺失记录。
2. **`fit.py`**：可复现建模、分组验证与残差诊断脚本（保存划分规则、预处理参数与拟合系数）。
3. **`model_report.md` / `metrics.csv`**：明确包含训练、交叉验证（分组/嵌套）、分组残差、公式单位及适用范围说明。
