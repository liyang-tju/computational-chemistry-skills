# 构建适配

## VASP 与补丁

根据目标 VASP 版本选择匹配的构建方式、工具链和补丁，不假设不同主版本或补丁组合可直接通用。原版、VTST、溶剂模型及其他改动使用独立目录和明确补丁顺序。

核对所需二进制变体，如标准、Gamma-only 或非共线版本；只报告实际构建和验证的变体。用户提供的授权源包与赝势不进入可公开分发的输出。

## MPI 与 GPU

检查 MPI 编译包装器所链接的编译器和运行时，避免编译和执行阶段混用 ABI 不兼容的组件。GPU 构建需要核对目标架构、驱动、运行库和编译工具链的支持交集；不要硬编码一种架构到所有机器。

链接成功并不证明 GPU 路径可用。小型目标架构运行应检查程序实际使用的设备、并行布局及主要数值结果。登录节点无设备时延后到适当计算资源。

## 其他程序

CP2K、LAMMPS、PLUMED 等各有版本与可选包要求。先检查当前源码说明、构建选项和已安装能力，再设计适配；本文件不代表这些程序的所有后端已经经过验证。

系统缺少某个加速实现时，重复安装同一功能集合不会自动产生该实现。先核对具体 pair style、kspace style、库后端或自定义 action 的可用性。
