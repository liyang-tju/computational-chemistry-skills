# 图件与结构渲染

## 数据图

坐标标题包含物理量与单位，误差棒说明 SD、SE、CI 或重复差异。断点、缺失数据与不同参考类保持可辨识；对数坐标、双轴或截断范围只在确有表达需要时使用并明确标记。

采用现有 Matplotlib 样式后再创建图形，不通过大量 rcParams 重复实现用户样式。只有实现具体输出要求的设置才另外调整，例如需要可编辑 SVG 文本时设置字体输出方式。

保存图件时同时保留所用表格和绘图配置。SVG 曲线与文本尽量保持矢量，PDF 字体嵌入和字体授权按实际字体核对；不随意复制个人字体目录。

## 结构渲染

ASE/POV-Ray、OVITO 或其他工具由已安装能力与任务需求选择。记录源帧、旋转、镜头方向、投影、晶胞、元素/角色显示方式和透明度。

水分子遮挡可以通过明确的选择或透明度处理，但要保留科学图意。完整晶胞与裁剪视图分别标记；不为美观误删结构、重复原子或隐去关键反应物。

无图形界面环境可使用支持的离屏渲染路径；后端成功生成文件与用户实际看到交互界面分别报告。

## 输出

科研图默认交付可复用脚本及实际 PNG/SVG/PDF，而非只给代码或强制建立网页。只有用户要求或交互本身能解决任务时才增加交互形式。旧结果保留，更新使用新版本或在明确授权范围内修改。
