# 科研绘图与结构渲染

将已有数据和结构表达成可复现图件。先确认科学定义，绘图阶段不静默重新筛选样本、改变符号或混合参考类别。

## 工作流程

1. 明确读者要比较的量、单位、条件、误差含义和最终用途。已有图件需要修改时检查原脚本、数据和版本。
2. 选择能直接回答问题的图形，保留异构体、构型类别和重复标签。缺失值不画成零，不用视觉处理掩盖不同统计口径。
3. 读取当前用户或项目指定的 Matplotlib 样式，在导入 pyplot 后、创建图形前应用。可分享脚本通过配置指定样式；没有指定时使用默认样式，不依赖某个机器私有 style 名称。
4. 采用 Matplotlib 默认颜色循环，除非用户指定其他方案。字号、字体与图幅按用途处理，避免无关主题库覆盖指定样式。
5. 结构渲染遵循 [图件与渲染](references/figures-rendering.md)，记录视角、裁剪、透明度、周期映像及结构来源。
6. 输出 PNG 预览和需要的 SVG/PDF，保留可编辑文本与矢量曲线。复合图中的结构面板可以栅格嵌入，同时说明其编辑范围。
7. 查看实际渲染结果，核对裁切、标签、图例、单位和显示范围；修改保存为新版本，按用户授权处理旧版本。
8. 交付图件、绘图输入数据和独立脚本，不默认创建网站、交互应用或额外插件。

## 输出

图像、可编辑矢量文件、plot.py 及绘图数据。字体、样式和第三方素材只有在许可允许且确实需要时随包提供；不从个人系统目录自动打包。

## 使用约定

- 依赖路径、环境名称、调度资源和科学参数从当前请求、项目文件或运行配置获取；只读探测缺失的环境信息，关键科学选择不明确时再询问。
- 保留源数据与既有结果，使用新的输出位置；提交、取消作业或破坏性操作须在当前授权范围内进行。准备输入本身不等于授权提交。
- 生成的脚本采用顶部配置、清楚的输入输出和相对资源引用。当前运行的本机路径可以记录在运行产物中，不回写到可分享的技能文件。
