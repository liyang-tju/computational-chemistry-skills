# 反应性与 Voronoi CV

质子交换会使固定 O-H 配对失去化学意义。先明确要追踪固定原子、瞬时分子身份还是连续质子缺陷，选择规则影响观测量和偏置力。

Voronoi 分配需要明确候选重原子、可转移氢、组顺序、各类参考配位和分配函数。不同化学位点的参考值不能从水氧直接复制到所有原子。

离子距离或全配对量可能被溶剂中的其他离子对主导。通过分项贡献与简单结构检查反应位点是否实际决定 CV，不能仅凭总曲线平滑判定物理含义正确。

用于施力的 CV 要求连续且具有正确导数；硬阈值或电荷乘积符号切换可能产生不连续力。改写数学定义时同时重新推导或检查导数，并在小构型上对照有限差分。

自定义 action 的名称、参数和支持版本来自实际源码与当前二进制。没有可用实现时先说明所缺依赖，不将一个自定义名称视作所有 PLUMED 安装的内置能力。
