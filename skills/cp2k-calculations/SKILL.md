# CP2K 计算准备

准备 CP2K 优化、单点和 AIMD，保持体系、电子设置与系综选择可追溯。

## 工作流程

1. 明确 RUN_TYPE、组成、电荷、多重度、晶胞、PBC、温度和目标长度。读取现有输入、包含文件与实际软件环境，不从计算目录名猜安装位置。
2. 对每个 KIND 核对元素、基组、赝势及文件可用性；记录泛函、色散、网格、SCF 和电子求解策略。不同任务不自动共享某个数值精度。
3. 使周期性、Poisson 设置和模型几何匹配。明确 slab、孤立分子和三维液体的边界条件，不能仅改变 CELL 就视为边界处理完成。
4. 选择单点、优化或 MD 所需章节，检查自由度约束、质量、步长、温控和压控。目标步数与时间单位同时写清楚。
5. 续算明确 restart、波函数和需要恢复的动力学状态。温度或系综切换要标明哪些状态保留、重置以及是否需要重新平衡。
6. 配置轨迹、晶胞、能量和检查点输出，保证后续可以重建时间和变胞结构。输出间隔与检查点频率由任务需要确定。
7. 以版本支持的输入检查或获准的小型运行验证输入；较大运行提交到合适资源。启动成功不能代替目标完成与化学稳定性判断。

## 按需参考

- 初态、系综和状态转换：读取 [动力学与重启](references/md-restart.md)。

## 输出

CP2K 输入、依赖文件引用、作业脚本与参数摘要；清楚列出初始状态、输出频率、目标步数和重启关系。

## 使用约定

- 依赖路径、环境名称、调度资源和科学参数从当前请求、项目文件或运行配置获取；只读探测缺失的环境信息，关键科学选择不明确时再询问。
- 保留源数据与既有结果，使用新的输出位置；提交、取消作业或破坏性操作须在当前授权范围内进行。准备输入本身不等于授权提交。
- 生成的脚本采用顶部配置、清楚的输入输出和相对资源引用。当前运行的本机路径可以记录在运行产物中，不回写到可分享的技能文件。
