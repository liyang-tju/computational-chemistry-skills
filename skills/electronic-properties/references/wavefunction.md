# 波函数与 Multiwfn

选择含有所需信息的输入。MWFN、WFX、WFN、FCHK 等格式的内容应实查；Molden 或程序输出未必含完整基组、占据或密度信息。XYZ/PDB 的几何可以支持部分结构或 promolecular 分析，不能凭空提供轨道电子性质。

从 ORCA、Gaussian 等转换时核对输出几何、原子数、电子数、总电荷、多重度及转换警告。路径和辅助转换器来自本次环境，不硬编码版本目录。

Multiwfn 先在小型代表输入上确认实际菜单，再保存 answers.txt 并批量执行。版本变化可能改变菜单编号；加载警告应判断是否影响当前分析，影响所需信息时停止该项并说明原因。

noGUI 构建用于数值与文件导出，不承诺交互式三维窗口。特殊设置写到本次分析目录中的独立配置，不改全局 settings。

分子体积区分电子密度等值面、范德华/溶剂空腔等定义，记录阈值、网格和单位。定义敏感性与网格收敛分别分析，两个高度相关的体积也不自动等价。

ESP、RESP、键级、拓扑和弱相互作用分析保存对应模型和参数；同名数值不一定跨方法可直接比较。大网格与多线程任务同时考虑分配的 CPU 和内存。
