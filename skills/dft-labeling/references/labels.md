# 逐帧结果验收

每个 sample_id 对应明确的输入结构、电子状态、标注协议、运行目录与输出状态。至少区分未准备、未运行、运行中、失败和已通过科学检查，避免只依赖文件存在。

成功标签需要电子收敛和预期物理量有效；力数组与原子顺序匹配，能量定义、应力符号和单位清楚。能量缺失时不要从不相关阶段或旧日志补数。

固定原子仍可能有物理力；区分计算器原始力与 ASE 应用约束后返回的力。训练标签应符合目标模型协议，不能在不同数据源中混用被清零或被投影的约束力而不说明。

解析后重新读写代表帧核对字段与单位。电子数、电势、Fermi 能等额外字段采用实现明确的定义及参考标尺；字符串 metadata 也要保留来源映射。

chunk 中失败帧单独列出。重试保留旧尝试信息，并避免重复收集同一个 sample_id 的多个版本；若同一结构存在不同物理状态，使用能区分状态的标识。

传输时确认完整文件、结构计数与必要字段。哈希可作非阻断诊断，不能以哈希相等作为计算启动或续算门槛。远程主机、账户、绝对路径和认证信息仅属于本次运行配置。
