# MD 协议

## 力场与单位

确认 real、metal 或其他 unit style，并相应解释时间、能量、长度、电荷和弹簧常数。导入参数时不能只改数字格式而不转换单位。

明确 bonded、LJ、静电、混合规则、special_bonds 和约束算法。混合 pair_style 需要核对每对原子类型的实际适用项；缺失交叉项不能靠猜测自动补足。

## 电极

固定电荷、固定总电荷、恒电势及电荷平衡方案有不同约束和势能处理。明确指定的是单电极电势、两电极电势差还是某个参考标尺下的数值。

检查所用 electrode fix 与 kspace 实现、边界处理和软件包的兼容性。不要仅凭编译了 GPU/Kokkos 就假定每个相关求解器都有加速实现。

## 平衡与生产

分别记录最小化、温控平衡、密度或几何调整和生产采样。保持原始 packing 结构与各阶段末态可追溯。切换力场时，以明确相同的初态和其他条件建立独立对照。

密度比较使用声明的体相窗口，记录可用体积、时间范围与归一化。界面峰值不是体相密度；按密度反推补水量属于新模型估计，需重新构建和平衡。

## 重复与恢复

记录每个 replica 的结构、速度来源、种子和起点。RMSD 等分析需要统一参考定义与有效时间窗口。restart 的 fix 状态恢复取决于其实现，读取成功后仍要检查阶段连续性。
