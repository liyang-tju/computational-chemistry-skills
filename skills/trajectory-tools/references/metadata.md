# 数据表示与元数据

来源表建议包含 source_id、relative_path、source_frame、simulation_step、time、time_unit、segment_id 和 replica_id。未知值保留为空，并注明原因。数据集内标识用于跨机器对齐，避免依赖绝对路径字符串。

完整标注数据保存能量、力、应力和目标模型需要的电子量；记录单位、参考态和协议。抽取子体系后原体系的标量能量或力不再天然适用，应移除或重新定义这些标签。

待 DFT 标注几何通常移除预测能量、预测力、旧参考标签及不需要的动量，但保留当前任务要求的电子数、约束和来源。MD 初态通常保留几何、晶胞、PBC 及运行器明确需要的状态；速度是否保留由 fresh start 或 restart 语义决定，不能统一清除。

清理仅在新副本上进行。ASE calculator 也可能携带旧结果，不能只删除 info 中的 energy 就认为清理完成。清理前后核对几何、原子顺序及约束；来源放 sidecar 不等于丢弃来源。

逐帧晶胞、原子映射与单位是物理信息；不能为了让读取器接受文件而猜测或填造。
