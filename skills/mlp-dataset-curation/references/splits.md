# 重复、分组与划分

完全重复检查至少考虑元素/原子身份、晶胞、PBC、坐标及区分物理状态所需字段。近重复的容差与对称处理另行说明，不把能量相近直接作为结构等价标准。

相邻时间帧、同一母轨迹或同一结构扰动产生的样本往往相关。根据想评估的泛化问题，选择按轨迹、体系、构型族或条件分组；在组级别分配后再做合理分层。简单随机逐帧拆分不能说明对未见体系的泛化。

保留旧划分时，新增样本与旧数据的重复及组关联都要检查。发现冲突时列出选项，例如排除新增重复、按既有组归属加入或在明确授权后建立新划分版本；不要悄悄移动旧样本。

验证比例和种子是配置。小样本组可能无法同时出现在每个集合，需报告取舍，不能通过复制样本伪造覆盖。保留测试集只用于最终评估。

输出索引表至少含 sample_id、source_id、group_id、split、protocol_id。数据文件的框架特定字段与通用来源表可以分开保存；模型不需要的私有路径不必嵌入 extxyz。
